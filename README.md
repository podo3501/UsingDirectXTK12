# DirectXTK12 실습 프로젝트 요약

이 저장소는 **DirectX Tool Kit for DirectX12 (DirectXTK12)**의 Getting Started 튜토리얼 예제를 직접 실행하고 검증한 학습 기반 프로젝트입니다.

---

## 주요 학습·실습 항목

- **Graphics 기본 구성 요소 학습**
  - `DeviceResources`, `SpriteBatch`, `BasicEffect` 등 툴킷 주요 클래스 활용 확인

- **Sprites and Textures**  
  - 비트맵 기반 스프라이트 텍스처 로딩 및 화면 렌더링

- **Drawing Text**  
  - `SpriteFont`를 이용한 텍스트 렌더링 구현 (bitmap font 방식)

- **Simple Rendering**  
  - 2D 삼각형 렌더링, `BasicEffect`, `PrimitiveBatch` 활용

- **Line Drawing & Anti-Aliasing**  
  - 그리드 렌더링 기반 선 그리기, MSAA(다중 샘플 안티앨리어싱) 적용

- **3D Shapes**  
  - 큐브, 구 등 기본 3D 도형 그리기 기능 검증 (Getting Started 레시피 기반)

- **Rendering a Model**  
  - 외부 모델(.cmo, .sdkmesh 등) 렌더링 기능 실행 (Toolkit의 `Model` 클래스 기반)

- **Animating Using Model Bones**  
  - 본 애니메이션 기반 모델 움직임 구현

- **Using Skinned Models**  
  - 스키닝 처리가 들어간 모델 렌더링 동작 검증

- **Using Advanced Shaders**  
  - 복합 셰이더 효과 적용 예제 실행

- **Multistream Rendering & Instancing**  
  - 여러 스트림 렌더링 및 인스턴싱 기반 다중 객체 처리 테스트

- **Writing Custom Shaders**  
  - HLSL 기반 커스텀 픽셀 셰이더 작성 및 적용 테스트

- **Authoring an Effect**  
  - 효과(Effect) 파일 제작 및 툴킷에서 효과 사용 구조 이해

- **Using HDR Rendering**  
  - 고동적 범위(HDR) 렌더링 설정 및 이미지 표현 검증

- **Physically-Based Rendering (PBR)**  
  - 물리 기반 렌더링 기법 구현 및 시각 효과 확인
